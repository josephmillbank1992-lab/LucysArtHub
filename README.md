# Lucy's Belle Art Castle

A bright, princess-inspired art portfolio for Lucy, built as a small family project and Website Mill portfolio piece.

## Features

- Responsive gallery with category filters
- Random artwork button
- Persistent favourite hearts using localStorage
- Artwork lightbox
- Magic artwork swap
- Optional musical button chimes
- Sparkle cursor on desktop
- Confetti celebration
- Runaway button interaction
- Reduced-motion support
- Privacy-conscious copy: first name only, with no school, location, surname or contact details

The artwork in `/assets` belongs to Lucy and is used here with family permission.
